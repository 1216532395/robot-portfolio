## 第一个仿真脚本：三种数值积分解一个振子
问题：显式欧拉 s_{n+1} = s_n + Δt·f(s_n) 的每一步放大因子 |λ| = sqrt(1 + ωn²Δt²) > 1    
⇒ 无阻尼振荡用显式欧拉模拟，振幅必然指数增长，与 Δt 多小无关     
10 秒、Δt=0.01、ωn=2π 时预测振幅 ≈ (1+ωn²Δt²)^(N/2) = (1.00395)^500 ≈ 7.1 倍
无阻尼单自由度：m ẍ + k x = 0
定义 ωn = sqrt(k/m)  →  ẍ = -ωn² x
化成一阶形式（状态 s = [x, v]）：ṡ = f(s) = [v, -ωn² x]
解析解（x0=1, v0=0）：x(t) = cos(ωn t)   →  振幅恒为 1
### 验证过程
[1] 显式欧拉 10s 振幅 = 7.1x   (解析=1.00, 预测≈7.1)  [PASS]
[2] 辛欧拉 10s 振幅   = 1.0x   应≈1.0            [PASS]
[3] RK4 10s 振幅      = 1.00   应≈1.0            [PASS]
[4] RK4 vs 解析最大误差 = 8e-06 量级  应 <1e-3          [PASS]
[5] RK4 收敛阶比 e(0.04)/e(0.02) = 1x.x  应≈16       [PASS]
图已保存 d1_result.png（matplotlib 后端 = TkAgg / qtagg）
> 关于 `[4]` 的量级：RK4 的误差**不是来自振幅**（每步放大因子 $|R(i\theta)|=1-\theta^{6}/144$，$1000$ 步后仍是 $0.99996$），而几乎全部来自**相位滞后**：$R(i\theta)=e^{i\theta}-\frac{(i\theta)^5}{120}-\cdots$ 给出每步 $\arg R(i\theta)\approx\theta-\frac{\theta^5}{120}\cos\theta$，$\Delta t=0.01$（$\theta=0.0628$）累积 1000 步 → $\approx 8\times10^{-6}$ rad。**「RK4 很准」不等于「RK4 无误差」** —— 而 `[5]` 那一行（$\Delta t$ 减半误差缩到 $1/16$，因为总相位滞后 $\propto\theta^5\times N\propto\Delta t^4$）才是「四阶」的真正证据。

工程结论：仿真发散 ≠ 机器人控制器的错，很可能只是积分器选错了。所以以后遇到「仿真跑着跑着飞了」，排查顺序是：①积分器与步长 → ②单位与符号 → ③控制器
**逐项 FAIL 怎么办：**
| 哪行 FAIL | 最可能的原因 | 修法 |
|---|---|---|
| `[1]` 没发散 | `f()` 写成了 `-2ζωv - ω²x` 时把 `ωn` 当成 `ωn²`；或状态顺序写成 `[v, x]` | 核对 `WN**2`；打印 `eu[:3]` 看形状 |
| `[2]` 发散或≠1 | 辛欧拉里用了**旧的** `v` 更新 `x`（那就退化成显式欧拉） | `x = x + dt*v` 必须在 `v` 更新**之后** |
| `[3]` 误差大 | RK4 系数写错（应为 1/6, 2/6, 2/6, 1/6） | 照抄 `k1+2k2+2k3+k4` |
| `[4]` 失败 | 时间数组与解数组长度不一致（差 1 个就会静默错位） | 统一用 `np.arange(n+1)*dt`，**不要用 `np.linspace` 配 `n` 步** |
| `[5]` 比值 ≈4 而非 16 | `k3` 写成了 `f(s + dt*k2)`（那是三阶写法），或对齐错位 | `k3 = f(s + dt/2*k2)`；两组 `t1/t2` 各自独立生成 |

### 4.5 立刻加两句「破坏性实验」（2 分钟，最有价值）
把脚本里的 `dt, n = 0.01, int(T_END / dt)`（此处代码应该修改为
dt = 0.01
n = int(T_END / dt)
改成：
```python
dt, n = 0.05, int(T_END / dt)      # 步长放大 5 倍（θ = ωn·dt 从 0.063 → 0.314）
```
重跑，观察 5 行断言怎么变：
| 断言 | dt=0.01 | dt=0.05（预测） | 原因 |
|---|---|---|---|
| `[1]` 显式欧拉振幅 | ≈7 | **≈1.2e4（爆炸）** | 每步放大 $\sqrt{1+\theta^2}=1.048$，200 步 $=e^{200\cdot0.047}$ |
| `[2]` 辛欧拉振幅 | ≈1.0 | **仍 ≈1.0** | 辛欧拉稳定域是 $\theta<2$，0.314 远在内 → **有界** |
| `[3]` RK4 振幅 | 1.00 | ≈1.00 | 每步 $|R(i\theta)|=1-\theta^6/144$，200 步后 0.9987 |
| `[4]` RK4 误差 | ~8e-6 | **~5e-3 → 会打印 [FAIL]** | 每步相位滞后 $\theta^5/120\cdot\cos\theta$，累积 $N$ 步；总量 $\propto\Delta t^4$ |
| 左图形状 | 曲线光滑 | 明显锯齿、相位跑偏 | 采样点变少，1 Hz 信号只剩 20 点/周期 | 

1.辛欧拉「振幅不炸」不等于「解得准」 —— 它的每步放大因子恰好为 1（$\det=1$ 且 $|\mathrm{tr}|<2$，特征值落在单位圆上），所以振幅有界；但频率被推偏了：$\tilde\omega\,\Delta t=\arccos(1-\theta^2/2)\Rightarrow$ 相对频率误差 $\approx\theta^2/24$（$\Delta t=0.01$ 时约 $1.6\times10^{-4}$，$\Delta t=0.05$ 时约 $4\times10^{-3}$）。这类「看着很稳、只是慢慢跑偏」的 bug 比爆炸难发现得多，而它正是真机上「仿真里对得好好的，实机一直慢半拍」的一种数学原型。
2.**断言会自动拦住你**：`[4]` 变 `[FAIL]` 就是你以后把 `dt` 调大时的报警器。**这就是「脚本自带验证」的价值** —— 第 17–22 周（阶段 D）你要把同样的思路用到 1 kHz 实时控制线程上（周期抖动 p99 断言、丢帧率断言）。
## 三个追问

1. **辛（半隐式）欧拉为什么不炸？** 提示：它是「保结构积分器」，离散版本的能量近似守恒；参考 [机器人控制教程](./机器人控制教程-从0到就业.md) §3.6 与 §5.2 的数值小节，搜 `symplectic integrator energy drift`。
2. **Δt 要多小才够？** 本例 $\omega_n=2\pi$（1 Hz）。两条不同的判据要分清：
   - **精度判据**（今天看到的）：RK4 在 $\Delta t=0.01$ 时误差 ~8e-6，$\Delta t=0.05$ 时升到 ~5e-3 并触发 `[FAIL]` → 说明「够不够小」是**方法 + Δt + 容差**三者共同决定的，不能只说「用 RK4 就准」。
   - **稳定/带宽判据**（真机上的那条）：控制频率 ≥ 10–20× 目标带宽，对 1 Hz 对象即 10–20 Hz（$\Delta t\le0.05\text{–}0.1$ s）。注意它只保证**环路稳定**，不保证**积分精度** —— 仿真步长通常要再小 10–100 倍。混淆这两条是新手最常见的错误之一。

3. **真机上「控制器算不完」是什么症状？** 今天你看到的是数学上的发散；真机上等价物是**周期抖动与丢帧**。这属于阶段 D（17–22 周）要练的能力，先记 ⚠️，别提前跳。
