问题：显式欧拉 s_{n+1} = s_n + Δt·f(s_n) 的每一步放大因子 |λ| = sqrt(1 + ωn²Δt²) > 1
     ⇒ 无阻尼振荡用显式欧拉模拟，振幅必然指数增长，与 Δt 多小无关
     10 秒、Δt=0.01、ωn=2π 时预测振幅 ≈ (1+ωn²Δt²)^(N/2) = (1.00395)^500 ≈ 7.1 倍
     
无阻尼单自由度：m ẍ + k x = 0
定义 ωn = sqrt(k/m)  →  ẍ = -ωn² x
化成一阶形式（状态 s = [x, v]）：ṡ = f(s) = [v, -ωn² x]
解析解（x0=1, v0=0）：x(t) = cos(ωn t)   →  振幅恒为 1
